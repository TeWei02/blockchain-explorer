區塊鏈技術與智慧合約開發的實驗筆記，記錄分散式帳本原理、合約開發與鏈上應用的探索過程。

## 狀態

> **實驗中**：以學習與概念驗證為主，程式碼與筆記將陸續補上。

## 內容規劃

| 類別 | 說明 |
|------|------|
| 基礎概念 | 區塊結構、共識機制、交易流程筆記 |
| 智慧合約 | Solidity 合約開發與測試範例 |
| 開發工具 | Hardhat / Foundry / Remix 使用紀錄 |
| 鏈上應用 | DeFi、NFT 等應用的技術拆解 |

## 學習方向

- 以太坊虛擬機（EVM）與 gas 機制
- 合約安全：重入攻擊、權限控制等常見漏洞
- 測試與部署流程自動化

## 目錄結構

```
blockchain-explorer/
├── notes/          # 技術筆記
├── contracts/      # 智慧合約範例
├── scripts/        # 部署與測試腳本
└── README.md
```
